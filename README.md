# Путь к себе — APK Builder

Этот репозиторий автоматически собирает APK из PWA.

## Как получить APK:

1. Нажми вкладку **Actions** вверху
2. Слева выбери **Build APK**
3. Нажми **Run workflow** → **Run workflow**
4. Подожди 2-3 минуты
5. Когда зелёная галочка — нажми на запуск
6. Внизу в разделе **Artifacts** скачай **nevahtovyj-apk**
